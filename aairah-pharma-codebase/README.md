# Aairah Pharma

A polished multi-page React + Vite pharmaceutical storefront and operations experience.

## Included pages

- Home / landing
- Shop catalogue
- Product details
- Cart and checkout
- Payment and order confirmation
- Login and registration
- About
- Admin login
- Inventory management
- Customer order details
- Compliance documents

## Run locally

Requirements: Node.js 20+ and pnpm.

```bash
pnpm install
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/aayerah-pharma run dev
```

Then open http://localhost:5173.

For the Replit workflow, use the artifact's configured web workflow so `PORT` and `BASE_PATH` are supplied automatically.
